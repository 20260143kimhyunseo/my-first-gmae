• 파라미터를 바꿨을 때 어떤 변화가 있었는지
실행 옵션(파라미터)을 변경하면서 프로그램의 동작 방식과 결과물이 달라지는 것을 확인했다.
예를 들어 --add-data 파라미터를 추가했을 때 이미지, 음악 파일 같은 외부 리소스가 실행 파일에 포함되어 .exe 파일만으로도 정상 실행할 수 있었다.
resource_path() 함수를 적용한 뒤에는 개발 환경과 실행 파일 환경에서 파일 경로를 자동으로 처리하여 오류가 줄어들었다.
빌드 옵션을 변경하면서 생성되는 파일의 구조와 실행 가능 여부가 달라졌으며, 필요한 설정을 조합하는 과정이 중요하다는 것을 확인했다.
