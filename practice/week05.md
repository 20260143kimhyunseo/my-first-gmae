2. 기획서 구체화 요청

1) 📌 게임 개요
장르: 생존형 아케이드 게임 (Survival Arcade Game)
플랫폼: PC (Pygame 기반)
목표: 제한된 시간 동안 생존하며 최대 점수를 획득하는 것


2) 🎯 게임 컨셉

“시간 제한 속에서 장애물을 회피하고, 보너스 아이템을 활용하여 생존 시간을 늘리는 전략형 스네이크 게임”

기존 스네이크 게임에
👉 시간 제한 + 장애물 + 보너스 시스템을 결합
단순 성장 게임 → 생존 + 전략 게임으로 확장

3) 🧠 핵심 시스템

3-1. 기본 플레이
뱀을 조작하여 먹이를 먹고 점수 획득
몸이 길어질수록 난이도 증가
자기 몸 또는 장애물 충돌 시 게임 종료

3-2. ⏱️ 시간 제한 시스템
난이도	제한 시간
Easy	120초
Normal	90초
Hard	60초
시간이 0이 되면 게임 종료
시간 관리가 핵심 전략 요소

3-3. 🟣 장애물 시스템
일정 시간마다 랜덤 생성
일정 시간이 지나면 자동 삭제
난이도	유지 시간
Easy	3초
Normal	5초
Hard	7초

👉 충돌 시 즉시 게임오버

3-4. 🟦 보너스 블럭 시스템
5초마다 생성
3초 후 사라짐

👉 획득 시:

시간 증가
점수 증가 (+50)
난이도	시간 증가
Easy	+3초
Normal	+3초
Hard	+5초
3-5. 🔄 이동 시스템
화면 끝 → 반대편 이동 (Wrap 방식)
공간 활용도 증가 및 전략성 강화


4) 🎮 조작 방식
방향키 (↑ ↓ ← →)로 이동


5) 🧱 게임 구조 (템플릿 기반)

본 게임은 이벤트 루프 기반 구조를 사용한다:

초기화
 → 입력 처리
 → 게임 로직
 → 충돌 처리
 → 화면 출력
 → 반복

👉 여기에 추가된 기능:

시간 시스템
장애물 생성 알고리즘
보너스 아이템 처리


6) 🎯 차별성 (핵심 포인트)

기존 스네이크 게임과의 차이:

요소	기존	본 게임
목표	무한 성장	제한 시간 생존
난이도	점진 증가	시간 + 장애물
전략	단순 회피	시간 관리 + 선택
시스템	없음	보너스 + 장애물


7) 🧠 알고리즘 요소
랜덤 위치 생성 알고리즘
충돌 판정 (AABB 방식)
시간 기반 이벤트 처리
리스트 기반 객체 관리 (뱀, 장애물, 아이템)


8) 🎨 UI 구성
점수 표시
난이도 표시
남은 시간 표시
게임 오버 화면


9) 🚀 확장 가능성

최고 점수 저장 시스템
효과음 및 배경음악

보스 패턴 및 탄막 시스템


10) 📌 기대 효과

3.구현 가능성 확인

## AI 답변에서 도움이 된 것
AI가 추천해 준 추가 룰인 장외로 나가더라도 죽지 않고 반대편으로 나오는 것이 도움이 되었으며
이를 기반으로 장애물의 생성과 제한 시간이 생길 수 있었다.
